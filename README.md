The FedEx Rate Quote Simulator is a lightweight, Postman-style application for testing the FedEx Rate API. It runs entirely in your web browser from a single HTML file — there is nothing to install, no account to create, and no data leaves your computer except the calls made directly to FedEx.
With it you can:
•	Request an OAuth bearer token from FedEx using your own API credentials.
•	Send a rate quote request to the FedEx sandbox (test) or production environment.
•	See the exact raw request sent to FedEx and the exact raw response returned, side by side — including status code, response time, and size.
•	View a summary table of returned rates (service, rate type, total charge, delivery).
